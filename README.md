# Air-Travel-1.0.0
[Standalone] Fast Travel Script | Airport to Airport Travel System

## Features
- Airport to Airport fast travel system
- **NEW**: Target system integration
- **NEW**: ox-lib support for enhanced UI
- Configurable travel locations
- Easy installation and setup

## Installation
1. Add `Air-Travel-1.0.0` to your resources folder
2. **IMPORTANT**: Remove "-1.0.0" from the folder name
3. Add to your `server.cfg`:
   ```
   ensure Air-Travel
   ```

## Dependencies
- **ox-lib** (for enhanced UI features)
- Target system (qb-target, ox_target, etc.)

## Configuration
- All configuration options available in `config.lua`
- **DO NOT TOUCH THE CLIENT FILE** unless you know what you are doing
